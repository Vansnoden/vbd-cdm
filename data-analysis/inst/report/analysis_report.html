VBD Analysis — Pan_African_Anopheles

Scope

This is a vector-centred analysis of the VBD CDM. Vectors (Anopheles spp.) are the study subject; environmental, resistance, bionomics, and case data are all interpreted in relation to them.

Vector bionomics

Code 
bs <- res$bionomics_summary
if (!is.null(err_of(bs))) {
  note("Bionomics analysis did not run: ", err_of(bs))
} else {
  any_shown <- FALSE
  for (nm in c("feeding", "biting_loc", "resting", "larval")) {
    df <- bs[[nm]]
    if (is.data.frame(df) && nrow(df) > 0) {
      cat("\n\n**", nm, "**\n\n")
      print(gt::gt(df))
      any_shown <- TRUE
    }
  }
  if (!any_shown) {
    note("No bionomics distributions available.")
  }
}
