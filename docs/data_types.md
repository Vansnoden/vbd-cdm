#### Supported data types

The CDM currently support the integration of various data types which come with thier own set of parameters or options during configuration.
These data types are: ```cog,csv,dta,geojson,gpkg,grib,json,nc,nc4,sas7bdat,sav,shp,tif,tsv,xlsx,xml```.

1. Cloud Optimized GeoTIFF (.cog)
2. Comma Separated Values (.csv)
3. Stata' Dataset Format (.dta)
4. GeoJSON (.geojson)
5. OGC GeoPackage (.gpkg)
6. Weather Data (.grib)
7. Javascript Weather Data (.json)
8. NetCDF (Network Common Data Form) (.nc)
9. NetCDF 4 (.nc4)
10. Database Binary Format (.sas7bdat)
11. Datafile for Statistical Package for the Social Sciences(SPSS) (.sav)
12. Shapefile (.shp)
13. Raster Data (.tif)
14. Tab Separated Values (.tsv)
15. Excel File (.xlsx)
16. Extensible Markup Language (.xml)
